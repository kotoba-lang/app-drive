# drive-app-component

`drive-app-ee6jpfxx` 向けの App companion component です。

## Endpoints

- `POST /api/mcp`
- `GET /healthz`

## MCP tools

- `CreateFolder`
- `UploadFile`
- `ListFiles`
- `GetFile`
- `DownloadFile`
- `MoveFile`
- `DeleteFile`
- `SearchFiles`

このコンポーネントは Drive UI と file metadata/blob API の両方を `kotodama WIT` で扱います。
